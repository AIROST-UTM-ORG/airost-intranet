# Client

React single-page application for the AIROST intranet portal.

## Available scripts

In the `client` directory:

- `npm start`: Starts the development server at [http://localhost:3000](http://localhost:3000).
- `npm test`: Runs client tests in interactive watch mode.
- `npm run test:ci`: Runs client tests once for CI environments (`CI=true`).
- `npm run build`: Compiles production static assets into `build/`.
