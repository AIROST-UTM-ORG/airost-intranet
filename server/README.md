# Server

Express REST API for the AIROST intranet portal.

## Available scripts

In the `server` directory:

- `npm run dev`: Starts the development server with nodemon auto-restart on port 4000.
- `npm start`: Runs the server with Node.js in production mode.
- `npm test`: Runs all server tests using Jest and in-memory MongoDB (`mongodb-memory-server`).
- `npm run test:unit`: Runs backend unit tests (`tests/unit`).
- `npm run test:integration`: Runs backend integration tests (`tests/integration`).
